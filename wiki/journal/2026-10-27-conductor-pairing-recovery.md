# Preserve pending Conductor pairing after a timeout

The live native development plugin exposed a cold-start timeout while polling browser approval. The transport now reports a typed timeout, and the controller retains the existing pairing code and original deadline when retrying. Offline cancellation still stops the poll. Regression cases cover retry identity, expiry, the unchanged hosted 30-second limit and a 120-second limit for the fixed localhost development origin.

The dedicated integration file and isolated local Conductor project are in use. Browser approval completed; a missing local sign-in profile initially caused a 401, and copying the existing verified local profile resolved it. The next authenticated context request returned 404 because the blank file had not yet been linked to the deliverable. Joe holds all 12 catalog roles on this test project only. No frame creation, selected-annotation submission or Functional Spec generation is certified by these results. External notification dispatch remains disabled.

Focused controller and transport checks passed 13 tests. Full verification and the live acceptance checklist remain pending for this follow-up. See [Conductor design workspaces](../topics/conductor-design-workspaces.md).

## Wireframe quality correction

Joe's live inspection found that the first actual wireframe lacked a useful skeleton. The renderer forced all text to 14px, emitted identical gray fills for containers and images, and accepted controls with clipped labels. The unreleased v1 contract now carries bounded optional font size, Auto Layout padding and gap, mirrored from COS with a refreshed source digest. Unknown fields and out-of-range presentation values still fail closed; the two draft implementations must ship together.

The generator requests screenshot-grounded structure and typography, parent-relative coordinates and correctly budgeted Auto Layout groups. It rejects text boxes shorter than one line, undersized controls and overflowing padded groups. The native renderer preserves those values, leaves structural containers unfilled, outlines image placeholders, pads control labels and reveals the resulting frame. Existing Design edits and earlier revisions are retained. Focused checks passed 41 plugin tests plus 10 COS generator tests. Native revision r4 was generated by the real local worker, applied by the development plugin and acknowledged by the receipt endpoint. Figma readback confirms frame 33:22, a 72px headline, 29px supporting copy and a padded 26px CTA label. The original reference, r1 and edited Design nodes 29:2–29:4 were preserved. Screenshot `/private/tmp/conductor-live-15-wireframe-r4.png` shows the actual output. Revisions r2 and r3 remain failed/cancelled evidence; neither is represented as a successful wireframe. Full follow-up CI and annotation-to-spec acceptance remain pending.
