# Complete the project guidance file workflow

[Issue 145](https://github.com/JFusco/design-passport/issues/145) closes the gap
between withdrawing an approval in the companion and clearing the advice in
Figma. The companion offers a removal file when a previously approved project
has no current approvals. Figma replaces only the reviewed advice and shows
the same project guidance revision as the companion. Import receipts open the
saved contribution for new and duplicate files.

Independent review verified the repairs for session-only guides, saved audit
history, and in-flight file selection. In a synthetic Figma Desktop file,
two reviewed advisories dropped to one and then zero after the corresponding
downloads. The base style guide remained and the grade and readiness stayed
the same. Reopening the saved audit showed the original advice. A local
companion browser test confirmed that same-named files opened the correct
contributions.
