# Model-assisted learning review, timing, and project budgets

## Summary and chosen defaults

Add on-demand project review to the local companion. GPT-6.1 Sol with high reasoning proposes approve/reject/defer decisions, supporting reasons, and complete wording/exception edits. The operator reviews and explicitly applies selected recommendations. Show an elapsed-seconds counter from run registration, per-run time and estimated cost, and obvious lifetime project spending/budget totals.

Use the existing local app and dedicated Supabase store. Initial project budgets are USD 0 until the operator explicitly sets a positive allowance. Select untouched, stale and deferred candidates by default; current approved/rejected candidates require explicit inclusion. Current shared approvals remain context-only and are managed through the manual controls. Source-guide attachment is optional. Preserve all existing evidence and decisions, with no retrospective cost records. Shared promotion, committed release exports, Figma import, hosted app deployment, background-on-import review, and additional providers remain outside this feature.
